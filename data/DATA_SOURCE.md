# Dataset Source Information

## Primary Dataset
- **Name**: Indian City Day-wise Air Quality Index Data
- **Source**: Central Pollution Control Board (CPCB), India via data.gov.in and Kaggle
- **Original URL**: https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india
- **Date Range**: 2015–2020 (varies by city)
- **Columns**: City, Date, PM2.5, PM10, NO2, SO2, CO, O3, AQI, AQI_Bucket
- **License**: Public domain / Open Government License India
- **Note**: This project includes a bundled demonstration dataset generated to match the schema and statistical properties of real CPCB data. It is clearly labelled as demonstration data. Users can upload their own real CSV data through the dashboard.

## Data Quality Notes
- Real CPCB data contains significant missing values for some pollutants and cities
- Not all cities have continuous monitoring for all pollutants
- AQI values in the real dataset are as reported by CPCB
